# 법적 고지·동의 구현 메모

> 법률 자문이 아닙니다. 2026-11 웹 조사(법령 해설·언론 요약 기준, law.go.kr 원문 미확인)를 바탕으로 구현했습니다.
> 시행 전에 전문가 검토와 아래 '확인할 것'을 처리해 주세요.

## 구현 요약

- **가입 화면(/signup)**
  - 체크박스는 '전체 동의'와 항목별로 나뉩니다. 모두 기본 해제이고, 전체 동의 뒤에도 하나씩 해제할 수 있습니다.
  - 필수 항목은 세 가지입니다: 이용약관 동의, 개인정보 수집·이용 및 국외 이전 **안내 확인**, 만 14세 이상 확인. 선택 항목은 광고성 정보 이메일 수신 하나입니다.
  - 필수 항목을 모두 체크해야 'Google로 가입하기'가 켜집니다.
  - 버튼을 누르면 폼이 `POST /api/auth/google`로 가고, 서버가 다시 필수 항목을 확인합니다. 선택값은 서명 쿠키(`rp_signup_consent`, 10분)에 담깁니다.
  - 콜백이 쿠키를 읽어 `user_consents`에 기록합니다. IP는 HMAC 해시로, User-Agent는 앞 200자만 저장합니다.
- **재동의 화면(/consent)**
  - 로그인했지만 현재 버전의 필수 기록이 없는 사용자는 앱 화면과 API가 이 화면으로 보냅니다. 기존 회원, 로그인 화면으로 처음 들어온 Google 사용자, 문서가 개정된 경우가 여기에 해당합니다.
  - 문서 버전은 `src/lib/legal/consents.ts`의 `*_VERSION`(시행일)입니다. 버전을 올리면 모두 다시 받습니다.
- **승인제(/pending)**
  - 새 가입자는 `pending` 상태로 시작합니다. 로그인은 되지만 안내 화면만 보이고, 앱 화면과 앱 API(LLM·가져오기·그래프 쓰기 포함)는 403입니다.
  - `ADMIN_EMAILS`에 있는 사용자는 로그인하거나 세션을 읽을 때 자동으로 admin + approved가 됩니다.
  - 관리자는 '관리 > 회원 관리'에서 승인·거절·정지·정지 해제를 합니다. 거절·정지하면 그 사용자의 세션이 모두 끊깁니다.
- **문서**: `/terms`(이용약관)와 `/privacy`(개인정보 처리방침)가 있습니다. 모든 화면 하단(BusinessInfo)에 두 링크를 두고, 처리방침은 굵게 표시합니다.
- **설정 > 계정**
  - 광고 수신 동의·철회와 동의 기록을 볼 수 있습니다.
  - 회원 탈퇴는 확인 문구를 입력해야 진행됩니다. 승인 대기 화면과 재동의 화면에서도 탈퇴할 수 있습니다.
  - 탈퇴하면 다음 순서로 지웁니다: Neo4j 그래프 → 저장소의 `users/<id>/` → DB 행(CASCADE, 사용자 키 `rate_events` 포함).
- **업로드 안내**: 새 진단 화면에 민감정보·주민등록번호 입력 주의와 'AI 학습에 쓰지 않음' 안내를 넣었습니다(`SensitiveInfoNotice`).

## 판단과 전제

1. **개인정보는 필수 '동의'가 아니라 '안내 확인'으로 받습니다.**
   - 서비스 제공에 필요한 처리는 계약 이행(법 제15조①4호, 2023.9.15 시행)을 근거로 하고 처리방침에 공개합니다.
   - 사용자가 요청한 '개인정보 수집·이용 표 + 거부권'은 안내 확인 항목 안에 표로 넣었습니다. 체크 문구도 '확인했습니다'로 동의와 구분했습니다.
   - '필수 동의'로 바꾸려면 `CONSENT_DOCS.privacy.kind`와 문구를 고치세요. 다만 2023 개정 취지는 필수 동의를 줄이는 쪽입니다.
2. **국외 이전은 위탁 겸 국외이전으로 보고 공개만 합니다**(제28조의8①3호). 별도 동의 체크박스는 없습니다.
   - 대상: Anthropic(미국), Vercel(미국 법인, 실행 리전 서울 icn1), Supabase(미국 법인, ap-northeast-2), Cloudflare R2(위치 미지정), Google(OAuth).
   - Neo4j는 사업자가 국내에서 직접 운영하므로(graph.example.com) 위탁·이전 표에 넣지 않았습니다.
3. **위탁 판단의 전제는 AI 사업자가 입력을 학습에 쓰지 않는 것입니다.** 수탁자가 자기 목적으로 쓰면 제3자 제공이 되어 별도 동의가 필요합니다.
   - 처리방침·약관·업로드 안내에 '학습에 쓰지 않음'을 적었습니다.
4. **OpenAI(Codex CLI)는 개발용 CLI 엔진**입니다. Vercel에서는 항상 꺼지므로 운영 처리방침에서 뺐습니다. 운영에서 켜면 위탁·국외이전 표에 추가해야 합니다.
5. **만 14세 미만은 가입을 받지 않습니다.** 확인은 자기 진술 체크로 하고, 법정대리인 동의 절차는 없습니다.
6. **휴면 제도는 운영하지 않습니다.** 유효기간제가 2023.9.15 폐지되어 탈퇴 전까지 보관합니다.
7. **광고 메일**
   - 정보통신망법 제50조 운영 의무를 처리방침 14항에 약속으로 적었습니다: (광고) 표시, 야간 전송 금지, 14일 내 처리 결과 통지, 2년마다 수신 동의 확인.
   - **실제 발송 기능은 없습니다.** 발송을 시작하기 전에 이 의무를 구현해야 합니다.
8. **공고 찾기(공용 공고)**: 모든 공고는 공용 공고를 먼저 만들고 보관 공고가 그것을 가리킵니다. URL로 가져온 공고와 직접 입력한 공고의 내용(회사·직무·JD 등)은 공유하고, 메모·상태·입력 주소와 가져온 사람은 공개하지 않습니다. 탈퇴해도 공고 내용은 남고 `created_by`만 null이 됩니다. 기존 직접 입력 공고는 마이그레이션에서 숨김으로 백필했습니다. 약관 제2·3·10조와 처리방침 2·3항에 적었습니다. 약관·처리방침 버전(2026-11-06)은 올리지 않았습니다(운영 회원이 관리자 1명뿐). 회원이 늘어난 뒤 바꾸면 버전을 올려야 합니다.
9. **외부 AI 앱 연결(MCP, docs/MCP.md)**: 이용자가 만든 개인 토큰으로 연결한 앱이 이용자 본인의 경험 그래프를 읽습니다. 이용자의 요청에 따라 본인에게 전달하는 것으로 보아 제3자 제공·위탁 표에 넣지 않았고, 처리방침 2항(토큰 이름·해시·앞부분·사용 일시)과 5항(전달 범위와 폐기로 멈추는 방법)에 적었습니다. 이메일·다른 테이블은 보내지 않습니다. 토큰은 탈퇴 시 FK CASCADE로 지워집니다. 8항과 같은 이유로 처리방침 버전은 올리지 않고 변경 이력에만 적었습니다. OAuth로 claude.ai 커넥터를 열면(2단계) 연결 앱 이름·client_id도 항목에 더해야 합니다.
10. **GitHub 연동(docs/GITHUB.md)**: 이용자가 연결한 GitHub 계정으로, 이용자가 고른 저장소의 정보를 읽어 경험 그래프 정리에 씁니다. GitHub은 이용자가 읽으라고 지시한 정보원이지 회사가 처리를 맡긴 수탁자가 아니므로 위탁·국외이전 표에 넣지 않았습니다(GitHub에 보내는 것은 로그인·권한 확인 요청뿐). 읽은 저장소 정보는 AI 처리를 위해 Anthropic으로 가므로 `OVERSEAS_TRANSFERS`의 Anthropic 항목에 'GitHub에서 가져온 저장소 정보'를 더했습니다. 처리방침 2항(GitHub 계정 식별자·아이디·프로필 사진 주소, 암호화 토큰, 저장소 정보 항목), 3항(보유 기간), 5항(GitHub에 제공하지 않음·비공개 저장소 조건·중단 방법)에 적었습니다.
    - 토큰(접근·갱신)은 AES-256-GCM으로 암호화해 저장하고(키 `GITHUB_TOKEN_ENC_KEY`) 응답·로그에 남기지 않습니다.
    - 연결 해제는 GitHub에서 앱 권한(grant)을 해지하고(최선 노력) 연결 행과 가져온 저장소 정보를 지웁니다. 경험 그래프에 적용한 내용은 이용자 자료로 남습니다. 탈퇴 시에도 권한 해지를 시도하고 FK CASCADE로 지웁니다.
    - 저장소에서는 이용자 본인이 쓴 커밋 메시지·PR 제목만 읽습니다(다른 기여자의 커밋은 개수만). README에는 제3자 이름이 있을 수 있어 앞부분(6000자)만 씁니다.
    - 비공개 저장소는 두 번의 허용(GitHub 앱 설치 때 저장소 선택 + 계정 설정의 '비공개 저장소도 가져오기')이 모두 있어야 읽고, 화면에 비공개임과 AI로 보내진다는 것을 표시합니다.
    - **결정(2026-11-07)**: 운영자 요청으로 `PRIVACY_VERSION`을 2026-11-07로 올렸습니다. AI 이용 기록·MCP·GitHub 항목을 한 번에 반영했고, 모든 회원이 다음 접속 때 /consent에서 다시 동의합니다. 이전 판(2026-11-06) 원문은 `/privacy/2026-11-06`(src/app/(legal)/privacy/2026-11-06, 표 데이터는 src/lib/legal/archive/)에 보관합니다. 시행 7일 전 공지 문구와 달리 즉시 시행했습니다 — 운영 회원이 관리자뿐이라 공지 기간을 두지 않았습니다.
11. **포트폴리오 원본 보관·프로필 사진(2026-11-08판)**
    - 포트폴리오 파일은 예전에는 뽑은 글만 저장하고 원본을 버렸지만, 이제 화면에 그대로 보여 주려고 원본을 보관합니다(`users/<u>/portfolios/<id>/original-*`, 소유자만 `GET /api/portfolios/[id]/original`). 처리방침 2항 표에 '포트폴리오 보관·보기' 행을 따로 두고, AI에는 원본이 아니라 뽑은 글과 설명만 보낸다는 점을 Anthropic 국외 이전 항목과 8항에 적었습니다. Cloudflare R2 항목에 원본·사진을 더했습니다.
    - 큰 파일은 브라우저가 R2 서명 주소로 바로 올립니다(`uploads/<u>/` 임시 자리 → 서버가 확인 뒤 `users/<u>/`로 복사, 임시 파일은 지움·수명 주기 규칙으로 1일 뒤 삭제 — docs/STORAGE.md). 임시 자리도 탈퇴 때 지웁니다.
    - 프로필 사진은 선택 기능입니다. 이용자가 올린 경우에만 처리하고, 서버가 3:4 JPEG로 다시 만들며 EXIF(촬영 위치 등)는 지웁니다. 이력서 머리글(미리보기·PDF)에만 쓰고 AI·다른 이용자에게 보내지 않습니다. 얼굴 사진이지만 신원 확인용 특징 정보를 뽑지 않으므로 민감정보(생체인식정보)로 처리하지 않습니다. 근거는 '계약 이행 — 이용자가 올린 경우에만'으로 적었습니다(별도 동의 체크박스 없음). 별도 선택 동의가 필요하다는 의견이 있으면 `CONSENT_PROCESSING`으로 옮기고 업로드 전에 동의를 받도록 바꾸세요.
    - 보유 기간(3항): 포트폴리오를 지우거나 내용을 바꾸면 이전 원본·글을, 사진을 지우거나 바꾸면 이전 사진을 바로 지웁니다. 파기(4항) 순서에 원본·사진을 더했습니다.
    - **결정(2026-11-08)**: 운영자 요청으로 `PRIVACY_VERSION`을 2026-11-08로 올렸습니다. 모든 회원이 다음 접속 때 /consent에서 다시 동의합니다. 이전 판(2026-11-07) 원문은 `/privacy/2026-11-07`(src/app/(legal)/privacy/2026-11-07, 표 데이터는 src/lib/legal/archive/privacy-data-2026-11-07.ts)에 보관합니다. 2026-11-07판과 같은 이유로 공지 기간 없이 시행했습니다.

## 문서를 고칠 때

- 이용약관을 고치면 `TERMS_VERSION`을, 처리방침을 고치면 `PRIVACY_VERSION`을 새 시행일로 바꿉니다. 각 페이지 '변경 이력'에도 한 줄 추가합니다.
  - 필수 항목의 버전이 바뀌면 모든 사용자가 /consent를 다시 거칩니다.
  - 영향이 작은 변경(수탁자 목록 등)은 버전을 올리지 않고 변경 이력만 남겨도 됩니다(작성지침 2026.4).
- 이전 버전 전문 보관: 개정할 때 이전 본문을 `/privacy/<version>` 정적 페이지로 남깁니다(시행령 제31조). 2026-11-06 판은 `/privacy/2026-11-06`, 2026-11-07 판은 `/privacy/2026-11-07`에 있습니다(이전 판 코드·데이터는 고치지 않는다).
