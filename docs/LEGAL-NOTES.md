# 법적 고지·동의 구현 메모

> 법률 자문이 아닙니다. 2026-11 웹 조사(법령 해설·언론 요약 기준, law.go.kr 원문 미확인)를 바탕으로 구현했습니다.
> 시행 전에 전문가 검토와 아래 '확인할 것'을 처리해 주세요.

## 구현 요약

- **가입 화면(/signup)**
  - 체크박스는 '전체 동의'와 항목별로 나뉩니다. 모두 기본 해제이고, 전체 동의 뒤에도 하나씩 해제할 수 있습니다.
  - 필수 항목은 세 가지입니다: 이용약관 동의, 개인정보 수집·이용 및 국외 이전 **안내 확인**, 만 14세 이상 확인. 선택 항목은 광고성 정보 이메일 수신 하나입니다.
  - 필수 항목을 모두 체크해야 'Google로 가입하기'가 켜집니다.
  - 버튼을 누르면 폼이 `POST /api/auth/google`로 가고, 서버가 다시 필수 항목을 확인합니다. 선택값은 서명 쿠키(`rp_signup_consent`, 10분)에 담깁니다.
  - 콜백이 쿠키를 읽어 `user_consents`에 기록합니다. IP는 HMAC 해시로, User-Agent는 앞 200자만 저장합니다.
- **재동의 화면(/consent)**
  - 로그인했지만 현재 버전의 필수 기록이 없는 사용자는 앱 화면과 API가 이 화면으로 보냅니다. 기존 회원, 로그인 화면으로 처음 들어온 Google 사용자, 문서가 개정된 경우가 여기에 해당합니다.
  - 문서 버전은 `src/lib/legal/consents.ts`의 `*_VERSION`(시행일)입니다. 버전을 올리면 모두 다시 받습니다.
- **승인제(/pending)**
  - 새 가입자는 `pending` 상태로 시작합니다. 로그인은 되지만 안내 화면만 보이고, 앱 화면과 앱 API(LLM·가져오기·그래프 쓰기 포함)는 403입니다.
  - `ADMIN_EMAILS`에 있는 사용자는 로그인하거나 세션을 읽을 때 자동으로 admin + approved가 됩니다.
  - 관리자는 '관리 > 회원 관리'에서 승인·거절·정지·정지 해제를 합니다. 거절·정지하면 그 사용자의 세션이 모두 끊깁니다.
- **문서**: `/terms`(이용약관)와 `/privacy`(개인정보 처리방침)가 있습니다. 모든 화면 하단(BusinessInfo)에 두 링크를 두고, 처리방침은 굵게 표시합니다.
- **설정 > 계정**
  - 광고 수신 동의·철회와 동의 기록을 볼 수 있습니다.
  - 회원 탈퇴는 확인 문구를 입력해야 진행됩니다. 승인 대기 화면과 재동의 화면에서도 탈퇴할 수 있습니다.
  - 탈퇴하면 다음 순서로 지웁니다: Neo4j 그래프 → 저장소의 `users/<id>/` → DB 행(CASCADE, 사용자 키 `rate_events` 포함).
- **업로드 안내**: 새 진단 화면에 민감정보·주민등록번호 입력 주의와 'AI 학습에 쓰지 않음' 안내를 넣었습니다(`SensitiveInfoNotice`).

## 판단과 전제

1. **개인정보는 필수 '동의'가 아니라 '안내 확인'으로 받습니다.**
   - 서비스 제공에 필요한 처리는 계약 이행(법 제15조①4호, 2023.9.15 시행)을 근거로 하고 처리방침에 공개합니다.
   - 사용자가 요청한 '개인정보 수집·이용 표 + 거부권'은 안내 확인 항목 안에 표로 넣었습니다. 체크 문구도 '확인했습니다'로 동의와 구분했습니다.
   - '필수 동의'로 바꾸려면 `CONSENT_DOCS.privacy.kind`와 문구를 고치세요. 다만 2023 개정 취지는 필수 동의를 줄이는 쪽입니다.
2. **국외 이전은 위탁 겸 국외이전으로 보고 공개만 합니다**(제28조의8①3호). 별도 동의 체크박스는 없습니다.
   - 대상: Anthropic(미국), Vercel(미국 법인, 실행 리전 서울 icn1), Supabase(미국 법인, ap-northeast-2), Cloudflare R2(위치 미지정), Google(OAuth).
   - Neo4j는 사업자가 국내에서 직접 운영하므로(graph.example.com) 위탁·이전 표에 넣지 않았습니다.
3. **위탁 판단의 전제는 AI 사업자가 입력을 학습에 쓰지 않는 것입니다.** 수탁자가 자기 목적으로 쓰면 제3자 제공이 되어 별도 동의가 필요합니다.
   - 처리방침·약관·업로드 안내에 '학습에 쓰지 않음'을 적었습니다.
4. **OpenAI(Codex CLI)는 개발용 CLI 엔진**입니다. Vercel에서는 항상 꺼지므로 운영 처리방침에서 뺐습니다. 운영에서 켜면 위탁·국외이전 표에 추가해야 합니다.
5. **만 14세 미만은 가입을 받지 않습니다.** 확인은 자기 진술 체크로 하고, 법정대리인 동의 절차는 없습니다.
6. **휴면 제도는 운영하지 않습니다.** 유효기간제가 2023.9.15 폐지되어 탈퇴 전까지 보관합니다.
7. **광고 메일**
   - 정보통신망법 제50조 운영 의무를 처리방침 14항에 약속으로 적었습니다: (광고) 표시, 야간 전송 금지, 14일 내 처리 결과 통지, 2년마다 수신 동의 확인.
   - **실제 발송 기능은 없습니다.** 발송을 시작하기 전에 이 의무를 구현해야 합니다.
8. **공고 찾기(공용 공고)**: 모든 공고는 공용 공고를 먼저 만들고 보관 공고가 그것을 가리킵니다. URL로 가져온 공고와 직접 입력한 공고의 내용(회사·직무·JD 등)은 공유하고, 메모·상태·입력 주소와 가져온 사람은 공개하지 않습니다. 탈퇴해도 공고 내용은 남고 `created_by`만 null이 됩니다. 기존 직접 입력 공고는 마이그레이션에서 숨김으로 백필했습니다. 약관 제2·3·10조와 처리방침 2·3항에 적었습니다. 약관·처리방침 버전(2026-11-06)은 올리지 않았습니다(운영 회원이 관리자 1명뿐). 회원이 늘어난 뒤 바꾸면 버전을 올려야 합니다.

## 문서를 고칠 때

- 이용약관을 고치면 `TERMS_VERSION`을, 처리방침을 고치면 `PRIVACY_VERSION`을 새 시행일로 바꿉니다. 각 페이지 '변경 이력'에도 한 줄 추가합니다.
  - 필수 항목의 버전이 바뀌면 모든 사용자가 /consent를 다시 거칩니다.
  - 영향이 작은 변경(수탁자 목록 등)은 버전을 올리지 않고 변경 이력만 남겨도 됩니다(작성지침 2026.4).
- 이전 버전 전문 보관: 지금은 최초 판이라 이전 버전 링크가 없습니다. 개정할 때 이전 본문을 `/privacy/<version>` 같은 정적 페이지로 남겨야 합니다(시행령 제31조).
